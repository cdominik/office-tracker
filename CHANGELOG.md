# Changelog

Notable changes to Office Planner, newest first. The running version is shown at the bottom of the
Setup rooms page and set by `APP_VERSION` in `config.php`.

When publishing a new release, bump `APP_VERSION` and add a section at the top in this form:

    ## 1.1 — YYYY-MM-DD
    - What changed, in a line or two each.
    - Note anything an admin must do when upgrading (usually nothing: the database migrates itself).
